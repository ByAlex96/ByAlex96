## En qué trabajo

| Área | Qué hago |
|---|---|
| **Backend .NET** | Corrijo y evoluciono una API en .NET 8 con Clean Architecture, CQRS (MediatR), Entity Framework Core y pruebas unitarias con xUnit y Moq |
| **Soporte N2 en producción** | Analizo la causa raíz con SQL, logs en Kibana/Elasticsearch y métricas de APM en New Relic; verifico datos reales antes de proponer cualquier corrección |
| **Gestión de servicio** | Tickets en Jira con SLA, documentación en Confluence, imputación en Tempo y cambios en producción por CAB (ITIL) |
| **Automatización** | Scripts en Python y PowerShell para consultas, seguimiento de tickets, informes y comprobaciones diarias |
| **Calidad** | Pruebas E2E con Playwright, integración continua con GitHub Actions y revisión de *pull requests* en Azure DevOps |
| **IA aplicada** | Agentes que diagnostican y preparan trabajo con **aprobación humana** en cada acción que escribe, y control del consumo |
